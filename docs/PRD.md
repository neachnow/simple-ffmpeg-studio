# FFmpeg Studio PRD（MVP）

**版本：** 1.0.3
**状态：** Windows 内部试用版；完整 FR 清单仍有后续规划项，当前可用功能以 README 为准
**产品形态：** Windows 本地桌面应用
**技术基线：** Python 3.12、PySide6、FFmpeg/FFprobe

## 1. 产品概述

FFmpeg Studio 是一个将 FFmpeg 常用能力以图形界面呈现的本地媒体处理工具。用户不需要记忆命令行参数，即可完成视频转码、裁剪、音频提取等高频任务；熟悉 FFmpeg 的用户仍可查看并复制实际生成的命令。

首版聚焦单机离线处理，不上传媒体文件，不提供云端账户或协作能力。

## 2. 目标与边界

### 2.1 产品目标

- 将高频 FFmpeg 操作转化为清晰、可验证的表单配置。
- 让用户在处理过程中看到真实进度、状态和可检索日志。
- 提供批量任务队列，避免用户重复配置同类处理。
- 在不牺牲易用性的前提下保留 FFmpeg 命令可见性和可复制性。

### 2.2 非目标（MVP 不做）

- 多轨视频剪辑、特效编辑、调色或 AI 生成能力（单轨画面预览及时间点选择已纳入 M5）。
- 网络视频下载、在线媒体转码、账号体系或同步。
- 直接编辑复杂 FFmpeg filter graph 的可视化节点系统。
- macOS/Linux 打包支持（架构应尽量保持跨平台）。

## 3. 用户与核心场景

| 用户 | 场景 | 成功标准 |
| --- | --- | --- |
| 普通内容创作者 | 将多个视频转换为 MP4/H.264，并缩小文件体积 | 无需输入命令即可得到可播放结果 |
| 运营/行政人员 | 提取视频音频，交付 MP3 或 WAV | 选择预设并完成批量输出 |
| 媒体技术人员 | 裁剪素材、调整编码参数、复制命令用于自动化 | 参数可控，命令与实际执行一致 |

## 4. 信息架构与界面

界面参考控制台式、留白充足的卡片布局：顶部采用中文 / English 双语 Tab 切换功能；左侧始终展示源媒体信息，并展示当前功能的参数设置；右侧固定展示任务队列、进度、命令预览与日志。切换 Tab 不清空任务状态。

### 4.1 页面/Tab

| 页面 | MVP 内容 |
| --- | --- |
| 概览 | 最近任务、运行中任务、常用入口、FFmpeg 可用状态 |
| 转码 | 格式、编码器、质量/码率、分辨率、帧率、音频、输出路径 |
| 视频分割 | 按原时长输出，或按指定每段时长生成多个视频 |
| 提取音频 | 按原时长或按指定每段时长提取，选择 MP3/AAC/WAV/FLAC |
| 处理状态 | 右侧固定显示等待/运行/完成/失败任务、开始与取消、进度、命令及日志 |
| 设置 | FFmpeg 路径、FFprobe 路径、默认输出目录、并发数、主题 |

后续页面：高级裁剪与变换、合并、字幕、图片/GIF、高级滤镜。

## 5. 功能需求

### FR-01 文件导入与媒体识别

- 支持文件选择和拖放导入一个或多个本地媒体文件。
- 使用 `ffprobe` 读取时长、容器、分辨率、帧率、视频/音频/字幕流。
- 不可识别或受损的文件应给出明确错误，且不加入可运行队列。

### FR-02 转码

- 支持输出 MP4、MKV、MOV、WebM、AVI；默认 MP4。
- 支持视频编码器 H.264、H.265、VP9，显示当前 FFmpeg 实际可用的编码器。
- 支持“高质量/平衡/小体积”预设，以及 CRF 或目标码率两种质量策略。
- 支持保留原始分辨率或选用常见预设；可选修改帧率。
- 支持复制视频流、复制音频流（若格式兼容）等快速处理选项。

### FR-03 裁剪与基础变换

- 支持指定开始时间与结束时间或时长。
- 支持顺/逆时针旋转 90°、水平/垂直翻转。
- 支持数值方式设置裁切宽高及起点；界面显示合法范围提示。

### FR-04 音频处理

- 支持从视频中提取音频并输出 MP3、AAC、WAV、FLAC。
- 支持设置码率、采样率与单声道/立体声。
- 支持基础音量增益（dB）。

### FR-05 任务队列与执行

- 每个输入文件对应一个独立任务，任务可在开始前编辑、移除或排序。
- 任务状态包括：等待中、运行中、已完成、已取消、失败。
- 支持开始、取消当前任务、取消全部、失败重试和打开输出文件夹。
- 默认单任务执行；设置中可调整并发数（初版上限为 2）。

### FR-06 进度、日志与命令

- 通过 FFmpeg 进度输出显示已处理时长、百分比、速度和预计剩余时间。
- 保留每项任务的完整标准输出、标准错误和最终退出码。
- 命令预览应与实际执行的参数数组严格一致，支持复制。
- 执行失败时展示简明错误原因，并可展开原始日志。

### FR-07 环境检测与设置

- 启动时检测 `ffmpeg` 与 `ffprobe` 是否可执行，并获取版本信息。
- 支持用户选择二进制路径；优先使用应用配置路径，其次使用系统 PATH。
- 首次运行未发现 FFmpeg 时，展示设置入口和安装说明链接/文案，不自动下载或安装。

## 6. 关键交互规则

- 输出文件默认写入输入文件所在目录下的 `FFmpeg Studio Output`，同名文件自动添加序号，不静默覆盖。
- 参数表单的非法值应在添加任务前拦截，并指出具体字段和修正建议。
- 运行中的任务不可修改核心处理参数；可取消后复制为新任务修改。
- 删除队列任务仅删除任务记录，绝不删除源文件或已生成的输出文件。
- 复杂参数默认隐藏在“高级选项”，避免普通用户误配置。

## 7. 非功能需求

- 所有媒体处理在本机离线完成；应用不收集媒体内容。
- 使用 `subprocess.Popen` 的参数列表执行 FFmpeg，禁止通过 shell 拼接整段命令。
- UI 在任务执行时保持可操作，FFmpeg 输出读取不得阻塞主线程。
- 启动后 3 秒内完成环境检测并展示主界面（不含首次扫描媒体）。
- 对带空格、中文和 Unicode 字符的路径进行完整支持。

## 8. 技术方案

### 8.1 模块划分

| 模块 | 职责 |
| --- | --- |
| `core.ffmpeg` | 查找二进制、读取版本、构造参数、启动/取消进程、解析进度 |
| `core.probe` | 调用并解析 ffprobe JSON，定义媒体元数据模型 |
| `core.jobs` | 任务模型、队列调度、状态流转、持久化 |
| `ui` | PySide6 主窗口、各功能页、任务卡片、对话框与主题 |
| `services.settings` | 用户设置读写与默认值 |
| `tests` | 参数构造、进度解析、状态流转、设置读写的自动化测试 |

### 8.2 数据与隐私

- 配置和任务历史保存在用户本机应用数据目录。
- 历史记录只保存路径、参数、状态和日志索引；源文件本身不复制。
- MVP 默认保留最近 100 条任务记录，用户可在设置中清除历史。

## 9. 验收标准（MVP）

1. 未配置 FFmpeg 时，用户能在设置中指定有效路径，并看见版本验证结果。
2. 用户拖入一段常见 MP4 后，能看见正确的分辨率、时长和音/视频流信息。
3. 用户使用“平衡”预设转出 MP4，任务进度可持续更新，完成后可打开结果文件。
4. 用户能批量添加至少 3 个任务，并取消其中运行任务而不影响其余等待任务。
5. 用户能提取 MP3、设置裁剪时间段，并在命令预览中看见相应参数。
6. 所有由应用生成的命令都以参数数组执行，在包含空格或中文的路径下正常工作。
