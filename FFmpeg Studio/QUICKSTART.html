四步上手

FROM INSTALL TO OUTPUT
1

保留完整程序目录

运行 FFmpeg Studio.exe。复制或分发时，请连同旁边的 _internal 文件夹一起保留；只复制 exe 会丢失运行库、Banner 和图标。

FFmpeg Studio\FFmpeg Studio.exe
FFmpeg Studio\_internal\source\banner.jfif
2

配置 FFmpeg 与 FFprobe

本程序不附带 FFmpeg。在“设置 / Settings”中分别选择 ffmpeg.exe 和 ffprobe.exe 的完整路径，然后点击“保存并检测”。

示例：C:\Tools\ffmpeg\bin\ffmpeg.exe
示例：C:\Tools\ffmpeg\bin\ffprobe.exe
3

导入视频并设置参数

拖入视频或点击“选择视频”。左侧会显示时长、分辨率和音轨。切换“转码”“视频分割”“裁剪”或“提取音频”标签，设置参数；时间轴可缩放并选择切点或范围。

4

加入队列并开始处理

点击当前功能页的“添加任务”，再到右侧点击“开始队列”。右侧可查看进度、命令和日志；处理完成后使用“打开位置”查看文件。

默认输出：源视频所在目录\FFmpeg Studio Output\
文件安全

程序不会覆盖源视频；遇到同名输出会自动编号。FFmpeg 与 FFprobe 可以放在任意目录，只需在设置中分别选对路径。

功能速览

COMMON WORKFLOWS

转码 / Transcode

输出 MP4，按高质量、平衡或小体积预设调整画质。

视频分割 / Split Video

按每段时长分割，或直接在时间轴上添加任意切点。

裁剪 / Trim

选择入点和出点，也可设置旋转、翻转及画面裁切。

提取音频 / Extract Audio

导出 MP3、AAC、WAV 或 FLAC，支持完整或分段时长。

时间轴 / Timeline

查看视频缩略图和时长标尺，缩放、拖动并微调切点。

任务队列 / Queue

查看处理进度与日志，调整等待任务顺序或重试失败任务。

常见问题

TROUBLESHOOTING
提示找不到 FFprobe，明明已经有 FFmpeg？

两者是不同的 exe，必须在设置中分别指定。把程序文件夹放在 FFmpeg 旁边不会自动识别；也可以将 FFmpeg 的 bin 目录加入 Windows PATH。

为什么显示自选图片，却看不到内置 Banner 或透明背景？

“显示位置”一次只应用一种模式。要保留内置 Banner 并显示透明背景，请选择“窗口背景”，再点击“保存并检测”；选择“替换顶部横幅”只会更换 Banner。点击“恢复默认背景”可清除自选图。

为什么导入视频时反复弹出命令行窗口？

请确认运行的是 1.0.4 或更新版本，并替换整个打包目录。旧版 exe 不会因旁边有新文件而自动升级。

复制到另一台电脑后图片或 FFmpeg 路径失效？

自选背景只保存文件路径，不会复制进程序包；请在新电脑重新选择图片。FFmpeg/FFprobe 也需要在新电脑准备并重新设置。内置 Banner 随完整的 _internal 目录提供。
